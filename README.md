# Covergo Playwright UI Automation Assignment

This project contains Playwright-based UI automation tests for https://www.saucedemo.com/

## 🛠 Installation

```bash
git clone <repo-url>
cd playwright-ui-automation
npm install
npx playwright install

Command to execute tests from terminal: npx playwright test

**Note:** I haven't created .gitignore because I want to reports and testdata to be there in the repo for reviewer's reference. But I'll have these files inside .gitignore to not have them on repo in realtime.
